使用方法

  1. 确保手机和电脑连接同一个 Wi-Fi / 局域网。
  2. 在手机浏览器中打开上面任意一个地址。
  3. 在手机页面输入上方 PIN，点击「配对」。
  4. 配对成功后会自动登录并进入 DSH 界面。
  5. 安卓手机可直接安装上面的 APK 获得全屏 App 体验；iPhone / 不安装 App 时可「添加到主屏幕」。
安全提示：PIN 页面只能在本机（127.0.0.1）打开；配对请求会限流，连续输错会被临时锁定。
