# 手机 App 安装与配对指南

桌面端已经装好并正在运行 **DSH Mobile Bridge**（插件监听端口 7860）。
手机端有两种用法，任选其一：

- **安卓 App（APK，推荐）**：全屏、无地址栏、文件上传/下载更顺滑，可直接装到手机。
- **手机浏览器（PWA）**：不用安装，打开网页后「添加到主屏幕」即可。

两种方式都需要**手机和电脑连接同一个 Wi-Fi**，并在首次使用时输入 6 位配对 PIN。

> 当前版本：桌面插件 **v0.3.14**（「沉浸式原生」新设计 + 侧栏简化 + 桌面专用入口屏蔽），安卓安装包 **v0.2.3**（versionCode 5，设置页可直接改服务器地址/外网地址，软键盘不再遮挡输入框）。
> APK 只是网页外壳，页面由桌面插件实时提供，H5 与 App 同源同款。

---

## 方式 A：安装安卓 App（APK，推荐）

### A1. 下载 APK

手机与电脑连同一 Wi-Fi 后，用手机浏览器打开（或扫码）：

```
http://<电脑局域网 IP>:7860/m/download/DSH-Mobile.apk
```

![APK 下载二维码](media/apk-download-qr.png)

> 电脑 IP 以桌面配对页 <http://127.0.0.1:7860/m/pair> 的「手机访问地址」为准，
> 该页面也会显示 APK 下载入口。

### A2. 安装

1. 浏览器会下载 `DSH-Mobile.apk`；
2. 点开下载文件，按系统提示允许「安装未知来源应用 / 允许来自此来源的应用」；
3. 安装完成后打开「DSH Mobile」。

### A3. 首次连接

- App 首次打开会显示设置页，已预填电脑地址 `http://<电脑局域网 IP>:7860/m/`；
- 直接点「连接」即可；若电脑 IP 变了，在输入框改成新的地址后点「连接」（点击「返回页面」/返回键可回到设置页）；
- 进入配对页面后，输入桌面配对页显示的 6 位 PIN，点「连接」；
- 配对成功后即进入桌面 DSH 的真实界面。

### App 特性

- 全屏无地址栏，深色状态栏/手势条适配；
- 支持网页中的文件选择（上传图片/文件）与下载（导出文件保存到下载目录）；
- 返回键：网页内可后退时后退，否则回到设置页（再按一次退出）；
- 换电脑/换网络时无需重新安装，改设置页地址即可。

## 方式 B：手机浏览器（PWA，免安装）

### B1. 打开页面

用手机浏览器（Android 用 Chrome，iPhone 用 Safari）打开：

```
http://<电脑局域网 IP>:7860/m/
```

或者直接扫描桌面端配对页上的二维码：

![配对二维码](media/pair-qr.png)

### B2. 输入配对 PIN

桌面端配对页会显示当前 6 位 PIN（也可以从桌面 DSH GUI 右下角的
「📱 手机连接」按钮打开该页）。在手机页面输入 PIN，点「连接」。

配对成功后会简短自动登录，然后手机就进入**桌面 DSH 的真实界面**，
看到的是桌面端同一个会话、同一个工作区。

### B3. 添加到主屏幕

- **Android / Chrome**：右上角菜单 `⋮` → 「添加到主屏幕」/「安装应用」。
- **iOS / Safari**：底部「分享」按钮 → 「添加到主屏幕」。

> PIN 在 DSH 重启或插件重载后会重新随机生成；配对成功后手机会保持登录
> （DSH 浏览器 Cookie 默认 30 天），一般不需要反复输入。

## 方式 C：外网访问（不在同一 Wi-Fi 时）

在电脑上运行：

```powershell
powershell -ExecutionPolicy Bypass -File packages\dsh-plugin-mobile-bridge\scripts\external-access.ps1
```

把打印的「外网地址」在手机上打开，输入「访问码（PIN）」即可。默认用 localhost.run 隧道；`-Provider serveo` 更快（首次出现 Serveo 警告页时点 Continue），`-Provider cloudflared` 需能解析 trycloudflare 域名。

注意：外网访问依赖第三方隧道服务，速度受隧道线路影响；长期使用建议 Tailscale 组网。用完按 Ctrl+C 关闭隧道。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 打不开页面 / App 一直转圈 | 确认手机与电脑同一 Wi-Fi；换用桌面配对页里列出的其他地址；路由器若开了「AP 隔离/访客网络」会导致手机与电脑互相不可见 |
| 提示 PIN 错误 | PIN 可能已刷新，看桌面配对页的当前 PIN；连续错误锁定后等 10 分钟或重启 DSH |
| 配对成功但页面空白 | 手机浏览器禁用 Cookie/无痕模式导致；用普通模式重新打开并配对（APK 请清除 App 数据后重试） |
| App 打开一直转圈/黑屏 | 通常是 App 里保存的服务器地址已失效（外网隧道已关闭、电脑 IP 变了）。页面 15 秒后会显示「桌面界面加载失败」，点「服务器设置」改地址；或直接重开 App 在连接页改地址 |
| App 里怎么换服务器/外网地址 | 在 App 内打开「设置」→「服务器地址」直接填写并保存（或连接页的「更换服务器地址」）；外网地址由桌面 `external-access.ps1` 生成 |
| 手机端点「打开/新建/添加工作区」没反应 | 这些操作会弹电脑端文件夹对话框，手机端已屏蔽（点击会提示）；请在电脑上操作。空工作区时请在电脑端打开/新建工作区后再用手机 |
| 电脑重启后手机失效 | 打开桌面配对页，重新配对即可 |
| 手机下载 APK 后无法安装 | 需要在系统设置里允许该浏览器/文件管理器「安装未知应用」；部分品牌手机需关闭「纯净模式」 |
| 想卸载 App | 系统应用管理中卸载「DSH Mobile」即可，不影响桌面端 |

## 安全提示

- App 只在局域网内直连你的电脑，不经过云端；传输为局域网明文 HTTP，
  请仅在可信 Wi-Fi 下使用，不要在公共 Wi-Fi 配对。
- 桌面配对页（`/m/pair`）与健康检查端口只允许本机访问；PIN 错误次数受限。
- APK 使用本地自签名证书（仅用于侧载安装），不要将 7860 端口映射到公网。
